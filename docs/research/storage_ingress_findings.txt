USB request versus settled worker
--------------------------------
Four additional groups in verify_usb_startup_ack.py execute ordinary Main's
outer USB call8000c220 through the public request8003b7e0. Profiles0/1/2 produce
worker commands20/80/200 (bits5/7/9), then give the request semaphore at801f9108
and wait indefinitely on its acknowledgement at801f9114. The command and argument
are at801f910c/801f9110. The original worker consumes and clears those words at
80045d5e..80045d62, then acknowledges at80046cce before proceeding to polling.

Six cold-worker cases (three profiles, USB setup success/failure) acknowledge
with SD-active localR7 zero, empty command slot and no unit0 setup or notification.
Acknowledgement also occurs when USB setup fails, so it is not proof of working
USB audio. An injected stale acknowledgement lets the outer call return and
update its mode without any worker execution: acknowledgement identity matters.

A second counterexample starts storage command40, then requests20/80/200 without
STOP. The existing USB instance remains PID088f and local SD-active state remains1;
disconnect still posts a unit0 notification. With real worker STOP command800
between requests, unit0 teardown occurs before acknowledgement, and the subsequent
audio request has inactive SD state and no later notification. This is a controlled
sequence, not a fault reproduced through the ordinary mixer UI.

Next binding
------------
The initial source contract must retain cold-worker history and associate the
first qualified audio-only request with its actual consumption/acknowledgement.
A requested mode, native return value or empty command word alone is inadequate.
Special boot modes and later storage-mode changes remain excluded for the first
capture trial; no recovery or readmission is added. This supplies concrete native
observation points, not a new READY callback or permission to enable the worker.
Cold reset completion, IRQ/source exclusion, physical buffer/cache ownership and
the initial mount witness still need to be joined into one admission contract.
