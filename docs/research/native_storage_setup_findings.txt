Eight groups compose original outer card setup 80009a40, mount 8005fc98,

Application acceptance is separate from filesystem readiness
------------------------------------------------------------
The earlier 65,526-cluster/eight-sector fixture is valid to the native FAT32
mount, but the application's capacity/cluster policy rejects it with status 10.
No folder creation or reload submission follows, even though native geometry
still returns a mounted volume. With 32 sectors per cluster, stock mount returns
2 and outer setup returns 0. These are tested layouts, not every accepted card
configuration.

Absent-card setup still returns zero while mount returns 1 and no native file
work occurs. A read-only folder failure detaches storage and withholds the extra
take. With the original stock availability getters restored, Record also refuses
admission and existing modeled file bytes remain unchanged. The normal recording
helper otherwise supplies availability/status fixtures; it cannot be used to
claim successful ordinary recording on this unavailable-card branch.

GPIO/card presence, driver registration/status callback arrival, outer detach
